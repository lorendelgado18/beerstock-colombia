# BeerStock Colombia

Aplicación Android para inventario de cervezas en bares colombianos.

## Descripción

La aplicación permitirá controlar inventario, registrar productos y gestionar stock desde Android.

## Funcionalidades

- Login
- Inventario
- Registro de cervezas
- Control de stock
- Reportes

## Tecnologías

- Android Studio
- SQLite
- GitHub
